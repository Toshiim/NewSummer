## Заметки разработки
### Первый этап
Реализованно уже:
- Доменная модель
- EF конфигурация
- 3 эндпоинта для управления сервисом(Get: /articles(с пагинацией, фильтрацией и сортировкой), /sources. Post /sources)
- RSS парсинг 
- Кравлинг статей(черезе [SmartReader](https://github.com/Strumenta/SmartReader))
- Суммаризация
- Hangfire
- Всё поднимается через docker-compose up (если у вас видеокарта Nvidia)

Парсинг RSS и кравлинг статей работает с любыми источниками, нужно их только добавить через Post /sources (тестилось на BBC, Habr, DTF).

### Второй этап
- Категоризация
- Поддержка ботов вне зависимости от платформы
- Реализация Телеграм бота с командами:
  - /start
  - /topics
  - /mysubs
  - /subscribe
  - /unsubscribe
  - /latest

Для добавления нового бота для любой платформы(Discord, whatever) необходимо только написать Handler вызывающий команды и Sender форматирующий и возвращающий пользователю ответ.
